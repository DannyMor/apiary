# Prototype UI

`apiary.html` is the single-file prototype that established the visual language and
every interaction, built with plain three.js and mock data. `apiary serve` serves it
at `/` until the React UI in `web/dist/` exists.

It is kept as the reference for the port: when the React version and this file
disagree about how something should look or behave, this file wins until the
difference is deliberate.
